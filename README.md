# Bench

Six HCI master’s programs, compared without the brochure.

Carnegie Mellon MHCI, Georgia Tech MS-HCI, UC Berkeley MIMS, University of Washington MHCI+D, University of Michigan MSI, and UT Austin MSIS: cost, outcomes, curriculum, and a visa prior you can argue with. Written for a product designer applying from India.

## Run

```bash
npm install
npm run dev
```

The dev server listens on port 8080.

## In the app

- A working rank, not a quality ladder
- Program pages with sources
- Compare two or three schools
- Decision framework, methodology, and a reading guide

Research notes live in `attachments/`.
