# Information Architecture
## HCI Programs Research & Comparison Platform

### Site Structure

**1. Homepage**
- Hero with overall ranking summary and key decision framing
- Quick navigation to all program pages
- Compare entry point (select 2–3 programs)
- “Best for” pathways: Product Design / UX Research / Product Management / Lowest Cost / Fastest Timeline
- Snapshot indices (Livability, Job Security, Future Proof, Selectivity, ROI) across programs
- Links to Application Guide and Decision Framework
- Dark mode toggle

**2. Compare Page**
- Side-by-side comparison of exactly 2 or 3 selected programs
- Toggleable categories: Overview, Cost, Outcomes, Curriculum, Application, Indices
- Official program links
- Export / share comparison
- Clear visual differentiation using saturated card system

**3. Individual Program Pages** (one per university)
- Overview and ranking rationale
- Curriculum & learning model
- Capstone / internship details
- Cohort & intensity notes (class size, workload, collaboration style)
- Cost of attendance breakdown (tuition + estimated living)
- Funding & scholarships
- Application readiness checklist
- Outcomes & job market
- Acceptance rate
- All indices with short explanations
- Visa chances (percentage range)
- SOP strategy notes
- Official program link (prominent)
- Related comparisons
- Data source & last updated

**4. Supporting Pages**
- Application Guide: Deadlines, materials checklist, portfolio tips, video essay notes
- Decision Framework: How to weigh indices and goals
- Indices Methodology: Scoring logic, data sources, limitations

### Navigation Model
- Top nav: Home · Compare · Programs (dropdown) · Application Guide · Decision Framework · Dark mode toggle
- Homepage: Cards linking to each program + prominent Compare CTA
- Program pages: Persistent “Compare this program” button
- Footer: Official links, indices methodology, data sources (cream in light mode)

### Content Principles
- Every program page is self-contained and detailed.
- Compare is the primary decision tool (max 3 programs).
- Indices are visible early but explained with methodology.
- Official program links are always prominent.
- Mobile: stacked cards and simplified comparison view.
